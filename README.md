# Animated Poster

Web page for my Motion Design 1 animated poster, a fictional collaboration with Herbert Bayer for the Great Ideas show.
It shows the final animation, four versions from After Effects, and the animation at the show.

Live at: https://jhzwiers-design.github.io/AnimatedPoster/

## Files
- `index.html` — the page
- `final.mp4` — final animation (show version, 35 s)
- `v4.mp4`, `v5.mp4`, `v6.mp4`, `v7.mp4` — versions from After Effects
- `show.mp4` — the animation at the show
- `images/` — poster frames, stills and process images

Keep the videos in the main folder, next to index.html.
